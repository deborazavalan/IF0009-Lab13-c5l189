# medpharm-frontend

Cliente SPA de MedPharm Express (Angular 19 Standalone).

```powershell
npm install
npx ng serve      # http://localhost:4200
npx ng build      # compilación de producción
```

Requiere el backend corriendo en `http://localhost:8080` (ver el `README.md` de la raíz del repositorio).
La URL de la API se configura en `src/app/app.constants.ts`.
